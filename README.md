# OpenWrt Build for Geniatech GTW360 (MTS-HC-001)

Этот репозиторий содержит предварительно собранные прошивки OpenWrt для устройства Geniatech GTW360 (также известно как "Домашний центр МТС" / MTS-HC-001), основанного на SoC NXP i.MX6ULL (Cortex-A7).

Сборка автоматизирована с помощью GitHub Actions и включает в себя все необходимые патчи ядра (DTS) и скрипты конфигурации для полноценной работы железа.

Характеристики устройства

SoC: NXP i.MX6ULL (до 792 МГц)

RAM: 512МБ

Flash: 8ГБ eMMC

Wi-Fi: 2.4/5ГГц 802.11a/b/g/n/ac (Broadcom)

Zigbee: Nordic Semiconductor nRF52840

Сеть: Ethernet 10/100 Мбит/с

Готовые образы прошивки публикуются в разделе **[Releases](https://github.com/mrnman66/gtw360-openwrt-build/releases)**.

Обычно для первоначальной прошивки используется `zImage+rootfs.bin`, а для последующих обновлений — `sysupgrade.bin`.

Сборка собственной версии

Если вы хотите собрать прошивку на основе другого релиза OpenWrt или добавить свои пакеты:
1. Сделайте форк этого репозитория.
2. Внесите изменения в файлы внутри папки `custom/` (при необходимости).
3. Откройте вкладку Actions -> Build OpenWrt Custom Firmware.
4. Нажмите Run workflow и введите нужный официальный тег OpenWrt (например, `v25.12.5`).
5. После завершения сборки скачайте готовые файлы из раздела Releases вашего форка.
